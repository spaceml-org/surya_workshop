================================
Surya Science: Hands-on Workshop
================================

Welcome to the documentation for the **Surya Science: Hands-on Workshop**. This project serves as a resource hub for the 2026 hands-on workshop, which is designed to provide participants with practical experience in using Surya for developing downstream heliophysics applications. The documentation includes setup instructions, module descriptions, and interactive notebooks to guide users through the workshop content. Please note, this is a living document, and forms the basis of what we are calling the 'Missing Manual' to enable the community to fully realise the potential of Surya. We encourage contributions and feedback to help us improve and expand this resource.
